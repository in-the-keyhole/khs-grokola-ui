Git Commands
add Adds files changes in your working directory to your index.
branch List, create and manage working development streams
checkout Switch current development branch
clone Clone a repository into a new directory
commit Records commits changes that have been staged. Takes all of the changes written in the index, creates a new commit object pointing to it and sets the branch to point to that new commit.
config Sets configuration values for your user name, email, gpg key, preferred diff algorithm, file formats and more.
diff Show diff changes between staged files or other branches
fetch Download new branches and data from a remote repository and update local repository.
init Create an empty git repository or reinitialize an existing one
pull fetch from a remote repo and try to merge into the current branch
push Push your new branches and data to a remote repository
remote list, add, and delete remote repository aliases.

URL's along with a alias to a remote GIT repository are managed using this command.
reset undo changes and commits
rm Removes files from your index and your working directory so they will not be tracked.
stash Don't want to commit current changes but, "stash" current work in order to do something else, like work in another branch, or apply code in a different direction. Then come back later and retrieve your stashed work.
status Shows you the status of files in the index versus the working directory. Lists untracked,modified, and staged
CVS Commands
add Add file or directory for CM control. After adding commit must be issued to upload
checkout Checkout repository files and subdirectory, creates working copy of files of directories.
commit Commit current working directory changes to repository
release Release directory from version control
status Checked out files that have been modified
tag Tag a copy of current context
update Update working directory with repository differences
Subversion Commands
add Add file or directory for CM control. After adding commit must be issued to upload
checkout Checkout repository files and subdirectory, creates working copy of files of directories.
checkout Checkout project to local working directory from repository
copy Make a copy of the current working directory in the repository. Tag this copy with a version number. Used to create interim project releases. Referred to as tagging the project.
create Create a subversion repository
delete Delete files/directories from repository. Commit must be performed before elements are removed
diff Show differences between working directory and repository
import Import a new project into the subversion repository from a local drive.
list Get a list of projects in a repository
status See what has been updated in your working directory compared with the repository
update Update local working directory with latest from repository
