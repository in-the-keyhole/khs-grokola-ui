add

Description:

Add file or directory for CM control. After adding commit must be issued to upload

Options:

Example:

Add Directory 
$ svn add

checkout

Description:

Checkout repository files and subdirectory, creates working copy of files of directories.

Options:

-r-Specify version to checkout

Example:

Checkout project from repository

svn checkout http://nodename/repos/svn/trunk/parentPath

checkout

Description:

Checkout project to local working directory from repository

Options:

svn checkout file:///repository_name/project/trunk project

Example:

copy

Description:

Make a copy of the current working directory in the repository. Tag this copy with a version number. Used to create interim project releases. Referred to as tagging the project.

Options:

Example:

svn copy http://host_name/repos/project/trunk http://host_name/repos/project/tags/0.1.0 -m "Tagging the 0.1.0 release of the project"

create

Description:

Create a subversion repository

Options:

Example:

From a local drive project directory 
svnadmin create

delete

Description:

Delete files/directories from repository. Commit must be performed before elements are removed

Options:

Example:

svn delete
Delete and specify a message 
svn delete -m "Deleting project dir" http://localhost/svn_dir/repository/project_dir
Network 
svn delete -m "Deleting project dir" http://localhost/svn_dir/repository/project_dir

diff

Description:

Show differences between working directory and repository

Options:

svn diff

Example:

import

Description:

Import a new project into the subversion repository from a local drive.

Options:

-m Specify a commit message

Example:

Import project to repository with message 
svn import project file:///repository_name/project -m "First Import"

list

Description:

Get a list of projects in a repository

Options:

svn list --verbose file:///repository_name/project

Example:

status

Description:

See what has been updated in your working directory compared with the repository

Options:

Example:

svn status

update

Description:

Update local working directory with latest from repository

Options:

Example:

svn update
